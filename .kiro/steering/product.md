# VSX - AI-Powered VS Code Extension

VSX is a Visual Studio Code extension that provides an intelligent coding assistant with multiple AI interaction modes. The extension integrates with various AI providers (Google Gemini, NVIDIA AI, Cerebras) to offer different approaches to code assistance.

## Key Features

- **Multiple AI Modes**: Ask, Legacy, and Duality modes for different interaction patterns
- **Multi-Provider Support**: Integrates with Gemini, NVIDIA, and Cerebras AI models
- **Webview-Based Chat Interface**: Rich UI for conversational AI interactions
- **File Operations**: Read, write, and manipulate files through AI assistance
- **Terminal Integration**: Execute commands through AI recommendations
- **Autopilot Mode**: Automatic application of AI-suggested changes

## Core Modes

- **Ask Mode**: Direct Q&A with AI models
- **Legacy Mode**: Traditional AI assistance with file and terminal tools
- **Duality Mode**: Dual-model system that breaks complex tasks into subtasks using primary/secondary model coordination

The extension is designed to enhance developer productivity by providing contextual AI assistance directly within the VS Code environment.
